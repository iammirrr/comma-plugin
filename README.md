# Comma

Write short video scripts with Claude or ChatGPT using reel breakdowns from Comma’s library. Save the scripts and ideas you choose to your own Comma workspace. The plugin includes six skills and connects to the hosted Comma MCP server.

See [Comma setup and account availability](https://comma.mirfahad.com/connect/) for the current Claude, ChatGPT and Codex connection options.

## Claude Code

```text
/plugin marketplace add iammirrr/comma-plugin
/plugin install comma@comma
```

## Codex

```sh
codex plugin marketplace add iammirrr/comma-plugin
```

Select Comma in the plugin directory and sign in to the Comma account you use on your iPhone. Your assistant and Comma accounts can use different email addresses.
